**New in 2.1**

- **Saved layouts.** Save the game area and where your apps go, then switch from the window, the tray icon or Ctrl+Alt+Shift+1…9.
- **Per-game sizes.** Give a game its own game area in Remembered apps.
- **Other monitor.** Drop a window on "Other monitor" (or press Ctrl+Alt+PageDown) and it fills your second screen.
- **Volume per app.** Point at the speaker on a window card to set its volume.
- **Do Not Disturb while gaming,** and a **play timer** with an optional break reminder.
- **Change any shortcut** in Settings → Shortcuts.
- **Tray menu** with layouts and the main switches.
- **Update check:** the app tells you about new versions and installs them in one click.
- **First-run setup** for new users.
- **.exe downloads.** No Python needed.

**Fixes**

- Clicking the tray icon, or starting the app while it was already running, could crash it. Fixed.
- A slow Windows volume mixer could freeze the app for a few seconds. Fixed.

Download **G9-Splitter-2.exe**, or **G9-Splitter-Classic.exe** for the classic version. The .zip files are the same apps as Python files.
